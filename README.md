# Competitor Analyzer

Аналіз топ-відео конкурентів на **YouTube, TikTok, Instagram**: перегляди,
лайки, коментарі, репости, транскрипція мовлення, опис кадрів і вивантаження
всього в CSV.

## Встановлення на macOS

Відкрий **Термінал** (Cmd+Пробіл, набери «Термінал») і встав одну команду:

    git clone https://github.com/moihospodin99-web/cf.git ~/Desktop/analyzer && cd ~/Desktop/analyzer && bash setup.command

Далі все ставиться саме: Homebrew, Python, ffmpeg, deno, модель розпізнавання
мовлення, Ollama. Займає від 30 хвилин, качається кілька гігабайтів.

Один раз запитає пароль від Mac — це Homebrew, так і має бути. Поки друкуєш
пароль, на екрані нічого не з'являється: ні крапок, ні зірочок. Це нормально,
друкуй наосліп і тисни Enter.

Після встановлення на робочому столі з'явиться ярлик **Competitor Analyzer** —
далі запускається звичайним подвійним клацанням.

## Запуск

Ярлик на робочому столі або `start.command` у теці програми.
Сторінка відкриється сама: http://127.0.0.1:5050

## Оновлення

    cd ~/Desktop/analyzer && git pull && bash setup.command

## Якщо щось пішло не так

**«Програму пошкоджено, перенести в Смітник»** — при встановленні через
`git clone` цього статися не повинно, бо позначку карантину git не ставить.
Якщо все ж з'явилось (теку скопіювали через Telegram чи флешку):

    cd ~/Desktop/analyzer && xattr -cr . && bash setup.command

**«Немає відповідних привілеїв доступу»** — загубився прапорець виконуваного
файлу:

    cd ~/Desktop/analyzer && chmod +x *.command && ./start.command

## Вимоги

macOS (Apple Silicon або Intel), інтернет, близько 10 ГБ вільного місця.
Ollama потрібна лише для колонки «Формат відео» — без неї решта працює.
